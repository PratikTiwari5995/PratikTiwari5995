## 📌 Featured Project

### 🛒 [Ecommerce Data Pipeline (Azure)](https://github.com/PratikTiwari5995/Ecommerce-data-pipeline)

A cloud-native, end-to-end data engineering pipeline that ingests raw ecommerce data, transforms it through a **Medallion Architecture (Bronze → Silver → Gold)** using **Azure Databricks** and **PySpark**, and serves business-ready insights via **Power BI**.

**Highlights:**
- Processes three fact domains — Order Items, Order Returns, and Order Shipments
- Secure, credential-free ADLS access via **Azure Managed Identity**
- Unified data governance with **Unity Catalog**
- All layers stored in **Delta Lake** format for reliability and time-travel

```
Ecommerce CSV  →  ADLS (Data Lake)  →  Databricks ETL/ELT  →  Bronze → Silver → Gold  →  Power BI
```
